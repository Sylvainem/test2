# _test2_

A small starter project initialized for learning and rapid development.

## Overview
This workspace contains a minimal static web app with a clean landing page and a simple interactive button.

## Files
- `index.html` — page structure
- `style.css` — visual styling
- `script.js` — interactive behavior

## Run locally
Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes
The project is intentionally lightweight so it can be expanded into a larger app without extra setup.
